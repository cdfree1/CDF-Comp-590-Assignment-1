# Comp 590 Assignment 1 Caleb Free
Simply put, the game I've created for this assignment has the player shoot balls through a moving hoop. In each round, the player is allowed ten shots and must make seven in order to win. Once the player has shot their tenth ball, the game checks their final score and displays a message corresponding to the result of the game. To start the game over, the player can then press the button on the top of their Google Cardboard, resetting their score and giving them ten more shots. 

This is, by definition, a game as it gives the player a direct goal/win condition along with a strict set of rules, both set by me, the creator, as well as the inherent limits of the environment the game was created in. One example of these inherent rules is that the player cannot move to make their shot at the hoop easier. Furthermore, though this is a very basic example, the game's ability to keep score creates a value system for the player.
